**技能名称：道闸主板调试**

## 用途

（D8 通用款 / D8 超强款 / D6 小主板 / D9 电源一体主板）的接线、基础调试、功能参数

## 回答协议（用户要求：思考后回答）

用户问这套主板的问题时，按下面顺序思考，不要凭记忆编造：

1. **先定位**：确认板型（D6/D8/D9）、使用场景（单机/同起同落/对开/灯带等）、
   具体现象或数码管显示（错误码先查错误码表）。
2. **查手册**：先查本文件速查区，无把握时读 `references/控制器手册全文.md` 对应页；
   接线端子级细节打开 `barrier-controller-study` 里对应页图核对后再答。
3. **给结论**：参数类问题给「参数号 + 默认值 + 范围 + 调整方向 + 预期效果」；
   排障类问题按可能性排序，给可执行步骤和验证方法（调完怎么确认对了）。
4. **标出处**：注明依据在基础篇第几页 / 进阶篇第几页，方便用户回原图核对。
5. **守边界**：手册没覆盖的内容如实说没覆盖，不猜参数、不编端子定义；
   涉及安全的（断电+松弹簧再松主轴螺丝、主板供电 0.5A 上限等）主动提醒。

## 板型区分

| 板型 | 特点 |
|---|---|
| D8 通用款 | 标准板，接线见基础篇 P2 |
| D8 超强款 | 接线同 D8；主板侧面有"超强款"标签（P3） |
| D6 小主板 | 接线同 D8；**不带光敏接口，不能接灯带**（P4） |
| D9 电源一体主板 | 电源一体，接线同 D8（P5）；支持广告灯带（P-44，P16） |

主板四键（P9）：起杆/加数值、落杆/减数值、菜单/确认、取消/退出；数码管显示。

## 接线要点

- **开闸信号**：主板"开"+"地"不分正负极，接相机开闸信号；**地感**：主板"地"+"地感"不分正负极，接车检器 3、4 脚（基础篇 P2）。
- **雷达（车辆检测雷达，用户现场经验，2026-11-05）**：信号线接主板"地感"+"地"（与车检器同口，不分正负极）；供电接 24V 电源。**搜不到雷达时断电重启唤醒**——先断电再重新上电，让雷达重新上电自检/被搜索到。
- **同起同落**（P6–P8）：两块相同主板的 开、地、地感 三个端口同名串联，线序一一对应、不能反。相机起杆接 开+地；车检器/雷达落杆接 地+地感。
- **红绿灯**（P12–P15）：杆上与箱体红绿灯电压一致、极性相同。主板直接供电时灯电流 ≤0.5A，超了必须独立外接电源（12V/24V），否则烧主板端口；杆上小红绿灯主板供电 ≤100mA。
- **光感/时控**（P15）：光感阈值或时控开关时间实现红绿灯白天灭、晚上亮变色；接收器分普通（白圆盘）与带光敏（红）两种（P11）。
- **广告灯带**（P16，D9）：P-44；电源 12V/24V，最大 ≤5A。

## 遥控器与加密（基础篇 P10、P17、P25、P26）

- 遥控器：3310 型（433 / 430 / M430 加密）；超远距离型 B6210（433）/ R6210（430）/ G6210（M430 加密）。
- 加密三组合：①全不加密（433/430）；②主板+遥控器加密、接收器普通 430；③接收器+遥控器加密、主板不加密。加密标识看激光丝印：遥控器背面、接收器正面、主板二维码旁。
- 学习（P-11，默认 0）：0=三键学习，1=一键学习（加密遥控器默认一键），4=学 200 个（改 4 后旧遥控全部失效、需重学）。学习/删除在 P-12（范围 0–50）。
- 车队模式（P-13，默认 0，0–3）：进入车队模式=常开、不处理地感。临时进入：遥控常开后长按开键 5 秒以上，蜂鸣器长鸣 2 秒；按关退出。
- **遥控器学不上先查 P-88**（控制接口禁用，默认 0）：按住遥控键运行灯快闪 = P88 被改成 2（遥控接口被禁用）；不快闪 = 接收器接触不良/损坏、遥控电量不足、少数为主板接收端口坏（P26）。

## 电机匹配与 P-10（基础篇 P18、P19）

- 电机线序按品牌端子图接（天龙/城邦/中兴/宇豪/汉江、禾日、台邦等，P18）。
- P-10 电机类型（默认 0）：起落反了改 1；按键起落显示 **Err7** = 电机类型错误，先改 2，再看起落顺序，反了改 3。**调试只用主板按键测，不用遥控器测**（防遥控学反/拿反）。
- 不兼容清单：智力星（ZLX）机芯不能直连常规主板（需改主板）；捷顺、富士、博思高整套系统不兼容；海康主板看电机线：无 NC 线可替换、有 NC 线不能；线性霍尔/特殊霍尔机芯不能替换（如百胜、安快某些机芯）。

## 基础调试流程

1. 装杆 → 通电第一次起落自动找限位（不可关闭）。P-18：0=找上下限位（默认），1=只找上限位→P-20 手动，2=只找下限位→P-20 手动；P-21 手动找上下限位基本用不到（P20）。
2. 按键试起落定 P-10 电机类型（P19）。
3. P-08 调水平（默认 15，0–255）：下垂加大、上翘减小；**绝不能为 0**（落杆后主板重启）。调到 1 还不平且曲臂顶机械限位 → 断电、松弹簧、松主轴螺丝，把杆放到位锁紧；保存后又下垂/手能推起 → P-30 关到位锁闸设 255 起落一次，仍不行调曲臂三点一线（P21、P22）。
4. P-09 调竖直（默认 15，0–255）：后仰加大、下垂减小；同样不能为 0。保存后又后仰 → P-29 开到位锁闸设 255 + 松一点弹簧再起落一次；顶限位同上机械处理（P23、P24）。
5. 速度（P27–P30）：起杆组 P00 速度（80）/ P02 减速角度（45）/ P03 结束速度（10）/ P06 加速时间（60）/ P25 减速结束角度（90）；落杆组 P01（80）/ P04（55）/ P05（5）/ P07（50）/ P26（10）。括号内为默认值。

⚠️ 安全：松主轴螺丝、调曲臂必须断电并松弹簧，禁止通电操作，防突然起落杆伤人。

## 进阶功能参数速查（进阶篇，括号内为默认值）

- **遇阻反弹**：P-14 触发时间（5，单位 0.05 秒，越小越快）/ P-15 力度（65，越小越灵敏）/ P-16 角度（10，角度内不生效，0=关闭）。误反弹调法：加大 P15 + 调大 P05 + P26 调小或 0；支撑脚架到地电机还转 → 调大 P08 让脚架到地、电机停。
- **起落转换缓冲**：P-22 起转落（80）/ P-23 落转起（50）/ P-24 停止（60），单位 0.01 秒，越小响应越快；越小反转瞬间电流越大，电源不足会重启。P-22 一般配 P42=2 用。
- **P-27 防砸端口复用**（默认 1）：=6 防砸口变开端口（对开场景：小车两闸都开、电动车只开一闸，电动车识别接防砸+地）；=7 变消防接口，触发后自动常开车队模式疏散。开关停/地感口损坏时也可用来替换端口。
- **无地感落杆**：P-32 自动落杆时间（0，秒，最大 255；跟车不落/掉头不过车时启用），落速由 P-73（40）定，建议比正常落速慢防砸；P-33 过车延时落杆（单位 0.1 秒，最大 25 秒，大车防中途丢信号砸车）。
- **P-34 地感计数**（默认 1）：0=不计数（过车离开即落；连续跟车开/感次数对不上不落杆时用；有砸车与后车出不去风险）；1=一车一杆；2/3 按需多次计数；4=最大计数 255。
- **地感杂项**：P-35 落杆到位前不检测角度（10，最大 45）；P-36 地感滴滴声（4，设 0 关，只对地感信号）；P-68 落杆遇地感只暂停不反转（1 启用，防跟车逃费，信号消失直接续落）；P-83 起杆初段不处理地感角度（20，最大 80）。
- **起杆优先 P-42**（默认 1）：0=开关停同级；1=起杆最优先（地感信号记忆等待）；2=起杆中地感消失立即落杆（不用等开到位）；50–80=起杆到设定角度后开始落杆。防跟车逃费/要求落杆快时用。P-43 信号判断时间（5，单位 0.01 秒）一般不改；网线接开闸偶发误起杆 → 改 15–20 观察是否网线氧化误判。
- **继电器输出 P-44**（默认 3）：1/3/6/9=光感灯带模式（3=灯带与红绿灯并存）；8=到位信号一直输出、起落过程中不输出（接地磅监控）；12=起落过程中一直输出、到位断开（报警灯）；17=到位后输出 1 秒断开（给相机到位反馈）。
- **光感灯带**：P-45 当前亮度（只读）/ P-46 开灯阈值（30，P45>P46 时亮灯）/ P-47 延时亮灯（10 秒）/ P-48 延时灭灯（150 秒）/ P-41 关灯阈值（与 P46 搭配，治灯箱照光感导致的亮灭闪烁）。
- **485 与维护**：P-55 波特率（改后断电重启生效）/ P-56 地址（多机同线分控）；P-78 自动发送状态（启用后不能再用 485 发指令控杆，会冲突致动作异常）；P-59 自动测试（老化测试）；P-60 恢复设置：5=只清遥控器，10=恢复出厂（遥控器与电机类型保留），15=完全恢复出厂（全清）。
- **断电起杆（超级电容）**：电容黄白线接 开+地 时免设参数；只有两根电源线的电容须 P-65=20、P-69=1。⚠️ P65=20 时 24V 电源跌破 20V 会误触发断电起杆、闸机落不下去。直杆/短栅栏用通用型电容，长杆/重型杆用超强款电容。
- **电源与重启类**：P-72 电源功率（90）：起落杆突然重启 → 调小限流（直杆/栅栏最小 50、重型最小 60），还不行查弹簧拉力或换更大功率电源。P-81 自检限位功率（50）：自检开关不到位 → 加大 P81 与 P-17 自检速度；自检撞机械限位重启 → 调小 P81 并搭配调小 P72；都调到最小仍重启 → 换更大功率电源。
- **蓝牙 P-82**：密码 8888；长按取消键显示 LY 后搜索连接，或进入 P82 显示 0 时搜索连接；模式 3 = 禁用蓝牙（仅最新程序有 1/2/3 模式）。

## 错误代码速查（进阶篇 S14）

| 代码 | 含义与处理 |
|---|---|
| Err0 | 清除遥控器/恢复出厂时确认值不正确 |
| Err1 / Err8 | 保留 |
| Err2 | 刹车反冲电压过高：弹簧匹配不好+速度过快 → 调弹簧与杆平衡、减小速度，或加大 P-66 阈值 |
| Err3 | 起杆堵转：弹簧断/起杆速度或结束速度过小 → 加大两者 |
| Err4 | 落杆堵转：弹簧太紧/未挂杆/落杆速度或结束速度过小 → 查弹簧、挂杆、加大速度 |
| Err5 | 起杆超时（>15 秒）→ 增加起杆速度与结束速度 |
| Err6 | 落杆超时（>15 秒）→ 增加落杆速度与结束速度 |
| Err7 | 电机类型错误 → P-10 改正确类型 |
| Err9 | 起杆中弹簧断等导致电机反转 |

状态显示：STOP 关到位 / CLOS 正在关 / OPEN 正在开 / HOLD 开到位 / LOCK 已锁定 / FLET 车队模式。
**IDLE（D8 说明书版显示表）：未接电机，或者电机霍尔故障，可能原因为接线松动** —— 不是待机！
排查：断电后查电机插头 W/V/U 三相线与 HW/HV/HU 霍尔线、5V/GND 是否松脱，重插上电；
线没问题再查霍尔线序/霍尔损坏。（2026-10-24 据官方说明书更正，此前误答为"待机"。）

**IDLE 时检测主板好坏（用户 2026-10-24 发的厂家教学视频，V3.0 板，视频存 barrier-controller-study/）**：
思路是把电机排除在外，单独验主板霍尔输入电路。①拔掉电机接线插头；②找一根短线，一端接电机端子的
GND；③长按菜单键进菜单，用开/+翻到 **P-59**（这块 V3.0 板面板标注为"自适应模式"，
与 D8 说明书 P-59=自动测试不同，属版本差异），按菜单进入数值界面（显示 0）；
④此时数码管上方**三个霍尔指示灯应全亮**——没全亮（只亮一个或全灭）→ 主板有问题；
⑤三灯全亮时，用短线分别把 GND 与 HW、HV、HU 逐个短接，每短接一路，对应的灯应熄灭；
三路都能熄灭 → **主板正常，IDLE 的故障在电机/霍尔/接线一侧**；某一路不灭 → 主板该路霍尔输入坏。

**电机侧霍尔检测法（用户 2026-10-24 发的第二个教学视频，25 秒，存 barrier-controller-study/）**：
与上面板检法配套——板检过关后，用这个验电机霍尔。电机正常接主板并通电，万用表打**直流电压档**，
黑表笔搭 GND，红表笔逐个搭 HW、HV、HU 三个霍尔信号端，同时另一只手**慢慢摇动电机手摇轮**：
每路的电压读数应在**约 0V 与约 5V 之间反复跳变**（视频实测读数在 0 点几到 4 点几之间来回变）。
三路都跳 → 电机霍尔正常；**某一路恒为 0V 或恒为 5V、摇轮也不变 → 该路霍尔损坏（或该路线断）**，
即 IDLE 的元凶，修电机/换霍尔板。

## 机械调试补充（整机机械侧，全文在 references/机械调试补充.md）

来源分层：本节是**整机机械口径**，与上面电控手册分开——前半是网络公开资料
（整机维护文章、减速机通用润滑规范与检修案例），机芯三处螺丝是**用户现场经验**
（2026-10-26 实拍标注）。品牌机芯齿轮箱拆解图、齿轮模数/齿数公开网络找不到，
本技能不编造，见全文末尾“未纳入”。

- **弹簧平衡 45° 法**：杆放到 45°、杆不动 = 平衡对了；上飘拧松、向下沉拧紧；
  多根弹簧各螺母旋转圈数保持一致。锯短杆后先退调节螺母，锯掉很多时按新杆长
  减弹簧根数或换细一号弹簧（与上面 P-08 调水平、Err3/Err4 对照）。
- **按现象查机械**：落杆慢无力（弹簧过紧/过松、机械阻力）、抖动异响（平衡弹簧、
  连接件松动、缺润滑）、手摇硬卡（断齿卡住、轴承抱死、曲臂顶死限位、蜗轮蜗杆
  须从电机尾轴摇）、摇把空转（离合没挂上、销轴脱落、曲臂松脱）、异常沉
  （弹簧断/脱钩）。全文有排查表。
- **减速箱润滑**：新机 100 小时首换油，之后每 6 个月换一次（恶劣工况 3–6 个月）；
  油位低于刻线及时补；油温明显升高（>60℃）伴异响 → 停机查齿面。
- **机芯三处螺丝（用户现场标注）**：红色 = 限位螺丝，左固定装左边、右固定装右边；
  绿色 = 换方向的螺丝，拆下后把拐臂翻到另一方向再拧紧，即左右向互换；
  蓝色 = 锁轴螺丝，调水平用。电控侧找限位用 P-18/19/20/21，两处不要混为一处。
- **必须停用**：防砸失效、杆体变形或连接件松动有坠落风险、立柱/基础松动倾斜、
  控制箱进水或线路破损、反复误动作原因未查明。维护周期（月/季/半年/年）与
  常备件、故障记录写法见全文。
