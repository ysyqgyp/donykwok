## 规格

- 供电：直流 24V ±10% 10A；电机功率最大 200W；静态功率 <2W
- 起/落杆速度 1%–100% 可调（速度均为电机功率百分比，数值越大越快）
- 环境：-40℃～80℃，湿度 30%～80%（无凝露）；噪音 <50db
- 特点：多重保护（过流/过载/短路/电机故障/电源反接）、支持外接遥控输入、光敏开广告闸灯光、防风防冻防锈、多种继电器输出模式；内置蓝牙调试（微信小程序「道闸调试软件」/扫码）
- 安装孔距（书 P22）：总长 185mm / 孔距 160mm；宽向 101.5mm、62mm、38mm、30mm；孔径 4.2mm

## 按键与显示

- 四键（左→右）：开/+、关/-、菜单、停止/取消。
- 进菜单：正常状态长按「菜单」3 秒，LED 显示 P-XX；开/+、关/- 选菜单项与调值；「菜单」确认保存才生效，按「停止/取消」退出则不生效；60 秒无操作蜂鸣器长鸣一声自动退出。
- LED 低功耗：上电低亮度，按任意键高亮；60 秒无按键变暗，2 分钟无按键关闭显示。
- P-67 可让数码管显示驱动电压/电流（工作模式短按「菜单」切换 V/A）。

### 数码管显示含义（书 P17）——重要

| 显示 | 含义 |
|---|---|
| **IDLE** | **未接电机，或者电机霍尔故障，可能原因为接线松动** |
| STOP | 道闸关到位 |
| CLOS | 道闸正在关 |
| OPEN | 道闸正在开 |
| HOLD | 道闸开到位 |
| LOCK | 道闸已锁定 |

（注：本表无 FLET；FLET 车队模式见进阶篇版本。）

## 接线端子（封面/书 P20 接线示意图）

- 顶部：电源 24V / 地；电机端子 W、V、U、GND、HW、HV、HU、5V；光感接口；遥控（天线）接口
- 底部左（继电器）：12V、地、常开1、公共、常开2 / 常闭2
- 底部右：开、关、停、地、地感、地磁、防砸、A、B（485）
- 电机接线（书 P21）：直流无刷电机按 W/V/U + 霍尔 HW/HV/HU + 5V/GND 对应接入

## 错误代码（本说明书版）

| 代码 | 含义 |
|---|---|
| Err0 | 确认值不正确（清遥控器/恢复出厂时需设正确确认值） |
| Err1 | 保留 |
| Err2 | 刹车反冲电压过高**警告**（弹簧匹配不好+速度过快）；不中断运行，蜂鸣器快鸣 5 声；处理：调平衡/降速，或加大 P-66 阈值 |
| Err3 | 起杆堵转：弹簧断、起杆速度或结束速度过小 → 加大两者 |
| Err4 | 落杆堵转：弹簧太紧、未挂杆、落杆速度或结束速度过小 |
| Err5 | 起杆超时（P-64，默认 20 秒）→ 增加起杆速度与结束速度 |
| Err6 | 落杆超时（P-64）→ 增加落杆速度与结束速度 |
| Err7 | 电机类型选择错误 → P-10 改正确类型 |
| Err8 | 保留 |
| Err9 | 起杆中弹簧断等导致电机反转 |
