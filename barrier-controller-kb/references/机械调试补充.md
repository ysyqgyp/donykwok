## 一、弹簧平衡：45° 自平衡法（整机厂手册常见口径）

- 弹簧是按杆长配规格的：杆越长，弹簧线径越粗、根数越多（某品牌整机说明书举例：3.3–4 米杆配 φ6.2×φ38×670 拉簧 2 根，4.7 米以上换 φ7 的 4 根——**各品牌机芯不通用，只可同品牌参考**）。
- 调法：杆放到 **45°，杆不动** = 平衡对了；上飘拧松、向下沉拧紧；多根弹簧的各螺母旋转圈数保持一致，防受力不均。
- 锯短杆后：杆变轻、原拉力相对过大，先退调节螺母；锯掉很多时光退螺母不够，按新杆长减弹簧根数或换细一号弹簧（与技能正文速查卡一致，不重复）。
- 对照电控：弹簧断了电机反转会报 Err9；弹簧过紧/过松会报 Err3/Err4 堵转。

## 二、按现象查机械（排查三条线：检测 / 机械平衡与结构 / 控制电气）

| 现象 | 机械侧优先排查 |
|---|---|
| 落杆缓慢、无力 | 弹簧过紧或过松、机械阻力；再看参数（与技能正文 P01/P05 对照） |
| 杆体抖动、异响 | 平衡弹簧、连接件松动、安装基础/立柱松动；传动机构缺润滑或有异物 |
| 手摇完全转不动（硬卡） | 减速箱断齿卡住、轴承抱死（进水锈蚀/缺油干磨）、曲臂连杆顶死机械限位或到死点、蜗轮蜗杆从输出端推不动（须从电机尾轴摇）、电磁刹车未释放 |
| 摇把能转、杆不跟 | 离合没挂上/摇把齿轮磨损、连杆销轴脱落、曲臂与主轴连接松脱 |
| 能摇但异常沉、某角度过不去 | 弹簧断或脱钩（平衡没了）、杆被外力顶住 |

## 三、减速箱 / 齿轮润滑（通用减速机规范，套用到道闸机芯）

- 新机：加注润滑油运行约 **100 小时后首换油**（并把内部污油冲洗干净）。
- 之后：**每 6 个月换一次**（8 小时工作制口径）；道闸是高频动作设备、户外粉尘多，工况恶劣时可缩短到 **3–6 个月**；连续长期运行的减速机有口径要求每 3 个月换一次。
- 日常：油位经常检查，低于油标刻线及时补；油温明显升高超过 60℃（或 85℃）、伴随异常噪音 → 停机查齿面胶合等故障后再用。
- 油品：常温一般用 40# 或 50# 机械油；延长寿命可用 70# / 90# 极压齿轮油；高低温工况另选。
- 判断油该换了：油色变深、油里有金属屑或油泥 → 磨损在发展，缩短换油周期并检测油品。

## 四、齿轮齿面故障的早期信号（减速机检修案例口径）

- **点蚀**：振动是个渐变过程——噪音变大、脚底能感到发麻；打开观察孔看齿面节线附近有细小凹坑且边缘在扩展；一旦进入扩展期，换油挡不住，及时换齿轮副比等到断齿代价小。
- 排查顺序：先取振动/温度数据（与啮合频率相关的边频带 → 齿面方向；以转频及其倍频为主 → 轴系方向），再停机看油 → 看齿面 → 看轴承 → 看轴与键。
- 齿轮箱里断齿卡死 → 手摇从输入端也转不动（"硬卡"最典型原因）。

## 五、维护周期建议（月 / 季 / 半年 / 年）

- **每月**：清洁探测窗口、目视检查杆体与连接件、观察起落动作。
- **每季度**：防砸测试、平衡与润滑检查、紧固件复紧。
- **每半年**：线路与接地检查、控制参数核对；减速箱换油（见第三节）。
- **每年**：结构状态评估、易损件更换评估。
- 常备件：弹簧、连接件等易损件 + 常用控制元件；多通道项目建议备件 + 故障记录（现象/原因/处理/更换部件型号/测试结果），积累到一定量能看出实际磨损周期。

## 六、必须停用处理的情况（不能靠复位继续用）

- 防砸功能失效或测试不通过
- 杆体变形、连接件松动有坠落风险
- 立柱或基础明显松动、倾斜
- 控制箱进水、线路破损
- 反复误动作且原因未查明

## 七、延长寿命的做法

- 按周期清洁与润滑，不带病运行；控制起落频率，避免高峰长时间连续动作
- 大风天气留意杆体受力与摆动；发现异响/抖动及时处理，避免演变为结构问题

## 八、机芯三处螺丝：用户现场标注（2026-10-26，用户实拍 + 原话）

> 来源层：**用户现场经验**，非厂家手册、非网络资料。照片：`道闸机芯-限位换向锁轴螺丝标注-20261026.jpg`（机芯实拍：曲臂/齿轮盘/电机/主板）。用户原话转录如下，括号内为整理时补的说明。

- **红色 = 限位螺丝**。用户原话：“左固定装左边，右固定装右边”——即左右两颗限位螺丝各就其位，左限位装左侧、右限位装右侧，装反则限位位置错。
- **绿色 = 换方向的螺丝**。用户原话：“螺丝取下来，把拐捣换一个方向，再把绿色螺丝拧一（原文至此截断）”。整理后理解：拆下绿色螺丝 → 把拐臂（用户原话作“拐捣”，疑指拐臂/曲柄）翻到另一方向 → 重新拧紧绿色螺丝，即完成道闸左右向互换。原文末尾截断，“拧紧”为整理补全，非用户原字。
- **蓝色 = 锁轴螺丝，调水平用**。即锁紧主轴的螺丝，用于调杆体水平（落杆水平位置校准）。

与技能正文的衔接：电控侧找限位用 P-18/19/20/21（见技能），此处是机械侧限位螺丝与换向、调水平的实物对应；两者不要混为一处。
